Projeto SENAC - Técnico em Desenvolvimento de Sistemas Projeto Integrador.

O sistema ADM System tem como foco solucionar problemas de controle financeiro da sua operação, sendo possível fazer o controle de caixa e gerar relatórios.

Agora o projeto foi estabelecido como refatorado de Ant para Maven, devido a utilização de recursos e facilitação na utilização de novas ferramentas.

Tecnologias: 
- JavaSwing para criação das interfaces
- JPA (Hibernate, VERSION 6.6.3 Final)
- MYSQL (MySQL connector, VERSION 8.0.33) 
- ITextPDF (biblioteca para uso de inclusão de PDF no projeto , VERSION 5.5.13.Final)
